# November 2026 questionnaires

Add candidate questionnaire PDFs to this folder. Use clear filenames, such as `Candidate Name - BNHCA 2026 Questionnaire.pdf`.

In `endorsements.html`, find the 2026 scaffold at the top of the content. Replace the pending paragraphs and copy the commented examples to add candidate endorsements, ballot measure positions, and questionnaire links grouped by race. Link every available response, including candidates BNHCA does not endorse.

PDF links start with `/questionnaires/2026/November/`. Replace spaces in filenames with `%20` in links. Remove the square-bracket placeholders before publishing.
